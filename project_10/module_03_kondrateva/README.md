# Модуль №3 - Система управления партнёрами

## Описание
Модуль предоставляет полнофункциональное приложение для управления партнёрами компании с графическим интерфейсом на Python/Tkinter.

## Структура проекта

```
project_10/module_03_kondrateva/
├── src/
│   ├── main.py              # Корневой компонент приложения
│   ├── index.py             # Точка входа
│   ├── components/
│   │   ├── partner_form.py  # Форма партнёра
│   │   └── README.md
│   ├── services/
│   │   ├── partners_service.py  # Сервис работы с партнёрами
│   │   └── README.md
│   ├── utils/
│   │   ├── validators.py    # Валидаторы данных
│   │   └── README.md
│   ├── hooks/
│   │   └── README.md
│   └── contexts/
│       └── README.md
├── public/
│   └── index.html           # Публичная документация
├── package.py               # Зависимости и скрипты
└── README.md               # Этот файл
```

## Установка и запуск

### Требования
- Python 3.8 или выше
- Tkinter (обычно входит в стандартную установку Python)

### Запуск
```bash
# Основной запуск
python src/index.py

# Или через конфигурацию
python package.py

# Прямой запуск главного окна
python src/main.py
```

## Основные возможности

### ✅ Реализовано
- **Добавление партнёров**: Форма с валидацией всех полей
- **Редактирование**: Загрузка и изменение существующих данных
- **Просмотр списка**: Табличное отображение всех партнёров
- **Валидация данных**: Проверка телефона, email, рейтинга
- **База данных**: SQLite для хранения информации
- **Обработка ошибок**: Информативные сообщения пользователю

### 📋 Поля партнёра
- **Наименование** (обязательное)
- **Тип партнёра** (выпадающий список)
- **Рейтинг** (целое число 0-1000)
- **Адрес**
- **ФИО директора**
- **Телефон** (с валидацией формата)
- **Email** (с валидацией)

## Технический стек

- **Python 3.8+** - основной язык
- **Tkinter** - графический интерфейс
- **SQLite** - база данных
- **Regex** - валидация данных

## Разработка

### Структура кода
- **Модульная архитектура** с разделением на компоненты, сервисы и утилиты
- **Валидация данных** на уровне утилит
- **Обработка ошибок** с информативными сообщениями
- **Типизация** с использованием typing

### Добавление новых функций
1. Создайте компонент в `src/components/`
2. Добавьте сервис в `src/services/` если нужен доступ к данным
3. Создайте валидаторы в `src/utils/` для новых полей
4. Обновите главное окно в `src/main.py`
